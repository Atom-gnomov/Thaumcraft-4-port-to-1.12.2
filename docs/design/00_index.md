# Unbound Technology — Канон дизайна

**Это единственный источник истины.** Всё, что написано в `docs/integration/*`
(слои v1–v5 и спеки фаз), с этого момента — **архив**: там сохранены ход
мысли и обоснования, но при любом расхождении верен канон.

## Как устроен канон

Сверху вниз: от «зачем» к «сколько EU и какая текстура».

| Слой | Файл | Отвечает на вопрос |
|---|---|---|
| 1. Замысел | [`01_vision.md`](01_vision.md) | Зачем мод существует, для кого, что он **не** делает |
| 2. Мир | [`02_world_model.md`](02_world_model.md) | Какие силы есть в мире, как связаны, законы обмена, глоссарий |
| 3. Прогрессия | [`03_progression.md`](03_progression.md) | Акты, тиры, что открывает что |
| 4. Системы | `04_systems/*.md` | Как работает механика (энергомост, пайплайны, перегрузка, броня…) |
| 5. Объекты | `05_objects/*.md` | Карточка каждого блока/предмета/сущности со всеми числами |

Шаблон карточки объекта — [`TEMPLATE_object.md`](TEMPLATE_object.md).
Ни один объект не считается спроектированным, пока в его карточке остаются
пустые обязательные поля.

## Правила ведения канона

1. **Один факт — одно место.** Число живёт в своей карточке (или в
   таблице курсов `02_world_model.md` §3, если это курс обмена). Остальные
   файлы **ссылаются**, а не копируют. Копия числа = будущее противоречие.
2. **Статус обязателен.** У каждого объекта и системы:
   ✅ реализовано · 🔨 в работе · 🔜 спроектировано · 🧊 отложено · ❄️ заморожено.
3. **Изменение канона — отдельный коммит** с пометкой, что именно
   поменялось и почему (старое значение → новое + причина).
4. **Реализация не спорит с каноном молча.** Разошлось — правится канон
   (с обоснованием) либо код. Комментарий «в коде иначе» недопустим.
5. **Архив не редактируем.** `docs/integration/*` — история; исправления
   вносятся только в канон.

**Дизайн закрыт по всем пяти тирам.** Осталось незакрытым по существу
только одно: массфабрикатор на эссенции (T5) — строка в таблице курсов
без системы и карточки (`03_progression.md` §6.4).

⚠️ **Главный риск проекта — не дизайн, а разрыв с кодом.** В сабмоде
реализованы два блока (оба конвертера) против 46 спроектированных
карточек. Рекомендация прежняя: следующий шаг — код T2, а не новые
карточки.
