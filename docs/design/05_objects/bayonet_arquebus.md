# Штыковая Аркебуза · Bayonet Arquebus

| | |
|---|---|
| **Registry** | NBT-состояние `unboundtech:flux_arquebus` (тег `UTBayonet`) |
| **Тип** | механика (не отдельный предмет) |
| **Тир** | T4 |
| **Акт** | IV. Резонанс |
| **Статус** | 🔜 спроектировано |
| **Класс** | `unboundtech.common.items.ItemFluxArquebus` + `RecipeBayonet` |

## 1. Зачем это существует

Единственная вещь в нашей оружейной ветке, которой в паке нет **как
класса**: не новое оружие, а **связка чужих**. Аркебуза перестаёт быть
беспомощной в упор, а меч (любой, включая нано-саблю IC2 и иридиевый METS)
получает вторую жизнь после того, как игрок пересел на дальнобой.

## 2. Место в мире

- **Кому нужен:** тому, кто уже носит аркебузу и не хочет держать во
  втором слоте меч.
- **Что открывает:** ничего.
- **Что требует:** `FLUX_ARQUEBUS` (T4) и любой меч.
- **С чем взаимодействует:** мечи всех модов сборки; ключ (разборка).
- **Что заменяет/дополняет:** дополняет **чужие** мечи, не конкурируя с
  ними: меч внутри остаётся собой и возвращается целым.

## 3. Лор

«Спор „чем добивать“ в цехах Механистов решили просто: привязали к стволу
то, чем добивали раньше. Тауматурги, увидев на аркебузе таумиевый клинок,
сочли это варварством. Через год у половины из них на аркебузе был
таумиевый клинок».

## 4. Механика

### 4.1. Сборка

Обычный верстак: **аркебуза + любой предмет, являющийся мечом** (проверка
по `ItemSword` **и** по `getToolClasses().contains("sword")`, чтобы ловить
чужие клинки, не наследующие ванильный класс) → та же аркебуза с тегом
`UTBayonet`, внутри которого лежит **полный NBT вложенного меча**.

- Зачарования, режимы, заряд EU вложенного меча **сохраняются**.
- Прочность вложенного меча замораживается: штыком её не расходуешь.
- **Разборка ключом** (Shift-ПКМ по воздуху): меч возвращается целым, со
  всем NBT; аркебуза остаётся.

### 4.2. Бой

- **ЛКМ:** удар штыком. Урон = **урон вложенного меча** (атрибут
  `ATTACK_DAMAGE` из его `getAttributeModifiers`) **+2** за древко.
- Скорость атаки — от вложенного меча.
- **Эффекты при ударе у вложенного меча не срабатывают**: нано-сабля не
  тратит EU, ихориевый меч не переключает режимы, катана METS не
  запускает свой особый удар. Мы берём **число**, а не поведение.
- **ПКМ:** выстрел, как обычно. Штык не мешает стрельбе.

**Почему только число.** Копировать чужие механики означало бы отвечать за
их баланс и ломаться от их обновлений. Правило простое и его видно в
тултипе: *«Штык: 25 урона (наследовано). Особые свойства клинка не
работают»*.

### 4.3. Ограничения

- Не принимаются: **Ихоро-Иридиевый Клинок** (`ichor_iridium_blade.md`
  §4.3), топоры, кирки, посохи, фокусы.
- Один штык за раз; второй меч не влезает.
- Штык **не зачаровывается отдельно** — зачарования только те, что были
  на мече.

## 5. Числа

| Параметр | Значение | Источник |
|---|---|---|
| Урон штыка | урон вложенного меча **+2** | собственное |
| Скорость атаки | вложенного меча | наследуется |
| Расход прочности меча | **0** | собственное |
| Расход прочности аркебузы | 1 за 4 удара штыком | собственное |
| Стоимость сборки | верстак, без доплат | собственное |

Итоговые числа для конкретных мечей **не перечисляем**: они живут в чужих
модах и меняются с их версиями (правило 1 канона).

## 7. Аспекты объекта

Аспекты аркебузы + `Telum 4` за клинок. Аспекты **вложенного меча не
складываются**: иначе сканирование штыка с ихориевым мечом внутри выдало
бы игроку бесплатное открытие редких аспектов.

## 8. Визуал

- **Модель:** модель вложенного меча приделана к стволу под углом, берётся
  из NBT (рендер предмета в предмете — как у витрин ТК).
- **Текстуры:** свои не нужны, кроме крепления-хомута
  (`items/bayonet_mount.png`).
- **Состояния:** [N/A] — статично.
- **Анимация:** при ударе штыком — колющий выпад, а не размах (отличается
  от обычного меча).
- **Как читается силуэт:** видно, **какой именно** меч приделан. Игрок
  узнаёт чужой клинок мгновенно.

## 10. Крайние случаи

| Ситуация | Поведение |
|---|---|
| Мод вложенного меча удалён из сборки | При разборке выпадает то, что смогло восстановиться; если предмета нет — в чат честное сообщение и штык просто исчезает. Аркебуза цела |
| Меч с зарядом EU (нано-сабля) | Заряд заморожен: не тратится и не восполняется |
| Меч ломался бы от использования | Не ломается: прочность заморожена |
| Игрок вставил проклятый/особый предмет чужого мода | Принимаем всё, что объявляет себя мечом; ответственность на моде, который так себя объявил |
| Аркебуза сломалась от выстрелов | Меч выпадает отдельно, целым |
| Штык на Аркебузе Механистов | Разрешён |
| Сервер перезапущен | Всё в NBT |
| Дюп через разборку | Невозможен: сборка **потребляет** меч, разборка **удаляет** тег |

## 11. Приёмка

1. Собрать с зачарованным алмазным мечом → урон и зачарования на месте.
2. Разобрать ключом → меч вернулся целым, с зачарованиями.
3. Собрать с нано-саблей IC2 → урон наследован, EU не тратится.
4. Ударить 100 раз → прочность меча не изменилась, аркебузы −25.
5. Попробовать вложить топор → отказ.
6. Попробовать вложить Ихоро-Иридиевый Клинок → отказ.

## 12. Открытые вопросы

1. ❓ Разрешать ли **зачарованные** мечи (сейчас да, `ranged_weapons.md`
   §6.4). Связка «Острота V + аркебуза» может оказаться сильнее любого
   нашего оружия. Мерить.
2. ❓ +2 за древко — вкусовое число. Если штык окажется строго лучше
   меча в руке, убрать прибавку в ноль: связка ценна удобством, а не
   уроном.
3. ⚠️ Рендер чужой модели внутри нашей — самая хрупкая часть визуала.
   Фолбэк: если модель не отрисовалась, показывать обобщённый клинок.
