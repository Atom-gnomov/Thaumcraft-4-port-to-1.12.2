# Эссентиальный Кабель · Essentia Conduit

| | |
|---|---|
| **Registry** | `unboundtech:essentia_conduit_{i,ii,iii}` |
| **Тип** | блок (три тира) |
| **Тир** | T3 (все три тира) |
| **Акт** | IV. Резонанс |
| **Статус** | 🔜 спроектировано |
| **Класс** | `unboundtech.common.blocks.BlockEssentiaConduit` (планируется) |

## 1. Зачем это существует

Магистраль между шинными узлами. Сам по себе кабель ничего не делает —
он только задаёт, **сколько аспектов** может идти по линии одновременно.
Платит за перекачку узел; кабель бесплатен в работе.

## 2. Место в мире

- **Кому нужен:** тому, кто ставит узлы.
- **Что открывает:** ничего.
- **Что требует:** `ESSENTIA_BUS`.
- **С чем взаимодействует:** только шинные узлы и накопитель. К трубам ТК
  напрямую **не** подключается — это работа узла.
- **Что заменяет:** ничего. Труба ТК остаётся дешёвым одноаспектным
  транспортом и никуда не девается.

## 3. Лор

«Внутри — не пустота, а стеклянная жила, в которой смыслы идут гуськом,
каждый по своей грани. Механисты зовут это оптоволокном, тауматурги —
дисциплиной. Чем чище стекло и чем благороднее оправа, тем больше рядов
удаётся уложить, не дав им столкнуться».

## 4. Механика

- **Периодичность:** [N/A] — кабель пассивен.
- **Радиус действия:** [N/A]; длина линии не ограничена.
- **Условия работы:** соединён минимум с одним узлом.
- **Условия отказа:** [N/A] — ломаться нечему; при обрыве линия просто
  делится надвое.
- **Пределы:** число одновременных каналов по тиру (§5). Канал занимает
  **труба, подключённая к узлу**, а не аспект: две трубы с одним аспектом
  съедят два канала.

## 5. Числа

| Тир | Каналов | Материал | Комментарий |
|---|---|---|---|
| **I** | 2 | закалённый таумий + стекло | Минимум, ради которого стоит строить |
| **II** | 4 | + вис-кристалл | Рабочая лошадка базы |
| **III** | 8 | + углеволокно IC2 (`crafting:carbon_fibre`) | Магистраль; углеволокно — T3-материал, иридий не нужен |

| Параметр | Значение |
|---|---|
| Потребление EU | **0** — платит узел |
| Хранит эссенцию | нет |
| Прочность / сопротивление | 1.0 / 5.0, кирка ≥1 |
| Свет | 0 |

**Почему минимум — два канала.** Одноканальная шина это обычная труба ТК,
только за электричество. Строить её незачем, поэтому I тир начинается с
двух.

## 6. Рецепт

- **Верстак:** арканный (все три тира).
- **Сетка (I тир):**

```
GTG     G — стекло ×2
        T — слиток закалённого таумия
```
даёт 4 сегмента. II тир — I тир + вис-кристалл (любой), III тир —
II тир + углеволокно IC2.

- **Аспекты крафта (по тирам, а не одной суммой):**
  I — `Ordo 2`, `Aer 2` (**4**); II — `Ordo 4`, `Aer 4` (**8**);
  III — `Ordo 6`, `Aer 5`, `Perditio 3` (**14**).
  ⚠️ Пересчитано по `recipe_calibration.md` §4 (было 20 / 30 / 50, а в
  сумме 100 — карточка мерилась как одна машина). Кабель — **расходник**,
  и мерить его надо не машинной вилкой, а самым дешёвым рецептом ТК:
  `WardedJar` стоит **1 вис**. Наш I тир даёт 4 сегмента за 4 вис, то есть
  **1 вис за сегмент** — ровно банка. Тянуть линию на полбазы больше не
  разоряет жезл.
- **Исследование-владелец:** `ESSENTIA_BUS` (общее с узлом; отдельной
  записи кабель не заслуживает — это расходник линии).

## 7. Аспекты объекта

По формуле; профиль I тира: `Vitreus ~4, Metallum ~3, Ordo ~2`.
⚠️ Профиль, а не расчёт.

## 8. Визуал

- **Модель:** тонкий кабель, соединяющийся с соседями (как кабели IC2).
- **Текстуры:** оплётка закалённого таумия; внутри просвечивают
  **2 / 4 / 8 жил** — тир читается глазом, без тултипа.
- **Состояния:** нет (кабель не светится).
- **Анимация:** [N/A].
- **Как читается силуэт:** тоньше труб ТК, толще кабелей IC2; число жил
  на торце — главный опознавательный знак.

## 10. Крайние случаи

| Ситуация | Поведение |
|---|---|
| Смешаны тиры в одной линии | Пропускная способность линии = **минимальный** тир в ней; статус узла это называет |
| Обрыв посередине | Две независимые линии |
| Кабель без узлов | Ничего не делает, EU не ест |
| Кабель через границу чанков | Работает; перекачка через выгруженный чанк не идёт |
| Сломан киркой | Выпадает предметом; эссенции в нём нет по определению |

## 11. Приёмка

1. Линия I тира + 3 трубы на узле → третья труба не обслуживается.
2. Заменить на II тир → все три пошли.
3. Разорвать линию → обе половины продолжают работать со своими узлами.
4. Смешать I и II тир в одной линии → работает по I.

## 12. Открытые вопросы

1. ✅ **РЕШЕНО:** III тир на **углеволокне**, а не иридии — иридий слишком
   дорог для расходника линии, и вся шина остаётся честным T3.
2. ❓ Ограничение «канал = подключённая труба, а не аспект» проще в
   реализации, но игрок может ожидать обратного. Проверить на живой базе.
