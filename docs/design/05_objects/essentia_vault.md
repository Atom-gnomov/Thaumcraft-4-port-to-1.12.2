| | |
|---|---|
| **Registry** | `unboundtech:essentia_vault_{casing,controller,golem_port}` |

| **Тир** | T3 |

| **Класс** | `unboundtech.common.tiles.TileEssentiaVaultController` (планируется) |

## 1. Зачем это существует

Склад «многого понемногу» на конце шины: место, где сходятся все аспекты
базы и откуда големы разносят их по банкам. Резервуар ТК держит больше
одного аспекта, банка — 64 одного; наш держит **много разных** и умеет
работать с шиной.

## 2. Место в мире

- **Кому нужен:** магу с большой алхимией.
- **Что открывает:** ничего; вершина логистической ветки T3.
- **Что требует:** `ESSENTIA_BUS`, корпуса машин IC2, закалённый таумий,
  энергосеть.
- **С чем взаимодействует:** шина (через узел), големы, трубы ТК, банки.
- **Что заменяет/дополняет:** **не заменяет Резервуар Эссенции ТК** — см.
  §5.1, там честное сравнение.

## 3. Лор

«Двадцать семь плит, и внутри — тишина, разгороженная на полки. Каждый
смысл лежит отдельно, подписанный, и не спорит с соседом. Големы бегают
сюда, как в библиотеку: взял, отнёс, вернул. Библиотека, впрочем, гаснет,
стоит выдернуть провод, — и тогда никто ничего не берёт».

## 4. Механика

- **Периодичность:** обслуживание входа/выхода — раз в **10 тиков**.
- **Радиус действия / зона:** [N/A] — структура 3×3×3.
- **Условия работы:** структура собрана целиком, есть EU.
- **Условия отказа:** структура разобрана → работа прекращается,
  содержимое сохраняется в контроллере; нет EU → 🔴, приём и выдача стоят.
- **Пределы:** **384 суммарно**, но не более **96 одного аспекта**.

### 4.1. Структура

**3×3×3** (общее соглашение мода, `02_world_model.md` §6): 26 корпусов +
**контроллер в центре одной грани**. Одна грань несёт **голем-порт** —
блок, к которому подходят големы.

### 4.2. Големы работают из коробки

Контроллер реализует `IAspectContainer` + `IEssentiaTransport`, а
`AIEssentiaGather`/`AIEssentiaEmpty` в порте ищут именно эти интерфейсы —
дописывать ничего не нужно. Голем видит накопитель как обычный контейнер.

### 4.3. Порядок выдачи

Алфавитный по тегу аспекта — то же правило, что у шинного узла и
Индукционного Тигля.

## 6. Рецепт

- **Верстак:** арканный (контроллер и голем-порт), обычный (корпуса).
- **Компоненты:** корпус — 4 закалённых таумия + корпус машины IC2 (даёт
  4 шт.); контроллер — корпус + вис-кристалл + продвинутая схема IC2;
  голем-порт — корпус + труба ТК.
- **Аспекты крафта:** контроллер — `Ordo 9`, `Aqua 7`, `Terra 4` (20);
  голем-порт — `Ordo 7`, `Aer 5` (12).
  ⚠️ Пересчитано по `recipe_calibration.md` §4: было 55 и 25 вис. Взята
  **нижняя** граница T3, а не середина, — по открытому вопросу §5.2 того
  же файла: у мультиблока 27 блоков корпуса уже являются ценой, и
  контроллеру незачем стоить как отдельная машина.
- **Исследование-владелец:** `ESSENTIA_VAULT` (T3), родитель —
  `ESSENTIA_BUS`. Стоимость: `Vacuos 12`, `Ordo 10`, `Machina 8`,
  `Praecantatio 4` — 4 аспекта, 34 единицы (T3).

## 7. Аспекты объекта

По формуле, для контроллера; профиль: `Metallum ~10, Machina ~5,
Ordo ~4, Vitreus ~3`. ⚠️ Профиль, а не расчёт.

## 8. Визуал

- **Модель:** корпуса — глухие плиты закалённого таумия с заклёпками;
  контроллер — с индикаторной полосой и маленьким окном; голем-порт — с
  нишей и полкой.
- **Состояния:** собран/не собран (у контроллера), заполнение показывает
  полоса 🔵→🟢, забит — 🔴.
- **Анимация:** редкие частицы эссенции у голем-порта.
- **Как читается силуэт:** единственная наша постройка размером 3×3×3.

## 9. Взаимодействие с игроком

- **ПКМ по контроллеру пустой рукой:** статус — «занято 137/384»,
  топ-5 аспектов, EU.
- **ПКМ фиалом:** забрать 8 единиц выбранного аспекта.
- **Shift-ПКМ ключом:** разборка контроллера с сохранением **всего**
  содержимого в предмете.
- **GUI:** нет (осознанно: чтение — через ПКМ и гогглы).
- **Гогглы:** полный список аспектов с количествами + EU-слой.

## 10. Крайние случаи

| Ситуация | Поведение |
|---|---|
| Структура разобрана игроком | Работа встаёт, содержимое в контроллере цело; собрал обратно — заработало |
| Контроллер сломан киркой | Содержимое теряется (ключом — сохраняется) |
| Переполнен по одному аспекту (96) | Приём именно этого аспекта прекращается, остальные идут дальше — одна пробка не вешает шину |
| Переполнен суммарно (384) | Приём прекращается целиком, 🔴 |
| Нет EU | Ни приёма, ни выдачи; голем уходит ни с чем |
| Голем и шина одновременно | Работают параллельно |
| Чанк выгружен | Не тикает, содержимое в NBT |
| Сервер перезапущен | Структура перепроверяется при загрузке контроллера |

## 11. Приёмка

1. Собрать 3×3×3, подать EU → контроллер сообщает «структура собрана».
2. Загнать 5 разных аспектов через шину → все приняты, статус показывает.
3. Загнать 96 единиц одного аспекта → 97-я не принимается, остальные идут.
4. Поставить голема-собирателя у порта → носит без правок кода.
5. Вынуть один корпус → работа встала, содержимое цело; вернуть — ок.
6. Разобрать контроллер ключом → всё содержимое в предмете.
