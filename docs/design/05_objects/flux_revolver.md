# Флюкс-Револьвер · Flux Revolver

| | |
|---|---|
| **Registry** | `unboundtech:flux_revolver` |
| **Тип** | предмет (дальнобойное оружие) |
| **Тир** | T3 |
| **Акт** | IV. Резонанс |
| **Статус** | 🔜 спроектировано |
| **Класс** | `unboundtech.common.items.ItemFluxRevolver` (планируется) |

## 1. Зачем это существует

Вход в оружейную ветку. Без него дальнобой начинался бы сразу с T4-й
аркебузы, и игрок узнавал бы про патроны в тот момент, когда у него уже
должно быть производство. Револьвер даёт **шесть выстрелов сразу после
конвертеров** — и тем самым объясняет, зачем потом строить Патронную Линию.

## 2. Место в мире

- **Кому нужен:** обоим; это первый предмет мода, который держат в руке
  ради боя, а не ради работы.
- **Что открывает:** `FLUX_ARQUEBUS` (T4) и вместе с ним всю ветку
  (`03_progression.md` §3).
- **Что требует:** `FLUX_CONDENSER` (T3), закалённый таумий, гильзы.
- **С чем взаимодействует:** патроны (`cartridges.md`), Патронная Линия.
- **Что заменяет/дополняет:** ничего. Пистолета в паке нет: METS начинает
  с пистолетов-пулемётов, IC2 — с лука.

## 3. Лор

«Первое, что делает подмастерье, получив право работать с алюментумом, —
кладёт его в трубку и смотрит, что будет. Второе — учится у мастера, как
делать это, оставаясь с рукой. Револьвер стоит ровно между первым и
вторым: он не мощный, он **предсказуемый**, а для первого ствола это
важнее».

## 4. Механика

- **Периодичность:** выстрел — раз в **10 тиков** (удержание ПКМ ведёт
  огонь очередью по барабану).
- **Радиус действия / зона:** дальность полёта снаряда **32 блока**,
  разброс 2° (заметный, но не случайный промах в упор).
- **Условия работы:** в барабане есть патрон.
- **Условия отказа:** барабан пуст → щелчок бойка (звук), выстрела нет,
  подсказка в тултипе.
- **Пределы:** барабан **6 патронов одного типа** — смешивать нельзя;
  перезарядка **15 тиков на патрон** (полный барабан — 90 тиков, полторы
  секунды с лишним, и это ощутимо).

### 4.1. Что делает выстрел

1. Урон **6**, умноженный на модификатор патрона (`cartridges.md` §4.2).
2. Эффект патрона в точке попадания.
3. С шансом 50 % гильза выпадает под ноги.

Снаряд — **сущность**, а не рейтрейс: он летит, его видно, его можно
опередить. Это отличает нашу стрельбу от METS-овских хитсканов и делает
дуэль с мобом читаемой.

## 5. Числа

| Параметр | Значение | Источник |
|---|---|---|
| Базовый урон | **6** | `ranged_weapons.md` §4.1 |
| Барабан | 6 патронов | там же |
| Темп | 1 выстрел / 10 тиков | собственное |
| Перезарядка | 15 тиков за патрон | `ranged_weapons.md` §4.1 |
| Дальность | 32 блока | собственное |
| Разброс | 2° | собственное |
| Прочность | 512 выстрелов, чинится закалённым таумием | собственное |
| Потребление EU | **нет** | оружие работает на патронах |

**Почему без EU.** Электрическое оружие в паке уже есть (METS, IC2), и
там электричество — суть. У нас суть — патрон; добавить сюда ещё и
зарядку значило бы сделать METS-ствол с лишним шагом.

## 6. Рецепт

- **Верстак:** арканный.
- **Сетка / компоненты:**

```
 T      T — слиток закалённого таумия
BTB     B — латунь / бронза IC2
 W      W — деревянная рукоять (палка)
```

- **Аспекты крафта:** `Ignis 20`, `Ordo 15`, `Perditio 10` — **только
  примордиалы** (арканный верстак берёт вис из жезла, а жезл хранит
  исключительно шесть прималов; `02_world_model.md` §6.8).
- **Нестабильность:** [N/A].
- **Исследование-владелец:** `FLUX_REVOLVER` (T3), родитель —
  `FLUX_CONDENSER`. complexity 2. Стоимость: `Telum 12`, `Ignis 10`,
  `Machina 8` — 3 аспекта, 30 единиц. Эта же запись выдаёт **гильзу,
  зажигательный и осветительный патроны**.
- **Альт-рецепты при аддонах:** нет.

## 7. Аспекты объекта

По формуле, арканная подпись. Ожидаемый профиль:
`Metallum ~8, Telum ~6, Instrumentum ~4, Praecantatio ~3`.

⚠️ Профиль, а не расчёт — точные числа из лога.

## 8. Визуал

- **Модель:** **3D**, `.json` с объёмом (решение владельца — плоские
  спрайты METS выглядят чужеродно). Короткий ствол, крупный барабан.
- **Текстуры:** `items/flux_revolver.png` + слой светящихся гнёзд.
- **Состояния:** барабан **проворачивается после каждого выстрела**;
  гнёзда светятся цветом заряженного патрона, отстрелянные — гаснут.
  Запас видно, не открывая инвентарь.
- **Анимация:** отдача (короткий кивок модели), дым из ствола, при
  перезарядке барабан откидывается вбок.
- **Как читается силуэт:** самое маленькое оружие в паке; ни с чем не
  спутать.

## 9. Взаимодействие с игроком

- **ПКМ:** выстрел (удержание — очередь по барабану).
- **Shift-ПКМ:** перезарядка патронами из инвентаря (тип берётся
  первый найденный; чтобы сменить тип, барабан надо разрядить).
- **ЛКМ:** обычный слабый удар рукоятью (2 урона) — не оружие ближнего
  боя, а вежливость к игроку.
- **GUI:** нет.
- **Тултип:** тип и число патронов в барабане, базовый урон.
- **Гогглы:** [N/A].

## 10. Крайние случаи

| Ситуация | Поведение |
|---|---|
| Перезарядка прервана (сменил предмет) | Уже дослано остаётся, остальное нет; прогресс не копится |
| В инвентаре патроны двух типов | Берётся первый по порядку слотов; сказано в тултипе |
| Стрельба в воде | Работает: алхимия, а не порох |
| Выстрел в упор флюкс-патроном | Облако задевает стрелка (`cartridges.md`) |
| Сервер перезапущен | Содержимое барабана в NBT |
| Предмет выпал/лежит в сундуке | Патроны остаются внутри |
| PvP-сервер, выстрел в союзника | Обычные правила урона мира; своей защиты от дружественного огня нет |
| Мод-античит на скорострельность | Темп фиксирован серверной стороной, клиент не решает |

## 11. Приёмка

1. Зарядить 6 зажигательных → 6 выстрелов, каждый поджигает.
2. Темп — не быстрее одного выстрела в 10 тиков даже при спаме ПКМ.
3. Перезарядка полного барабана — ~90 тиков.
4. Подобрать примерно половину гильз после 20 выстрелов.
5. Смена типа патрона требует разрядки.
6. Сравнить с ПП METS: наш заметно слабее по DPS и отличается эффектом.

## 12. Открытые вопросы

1. ❓ Урон 6 — прикидка. Мерить против стартового ПП METS: револьвер
   обязан проигрывать по DPS и выигрывать по эффекту.
2. ❓ Разрядка барабана (обратно в патроны) — сейчас есть. Если окажется
   лазейкой для «бесплатной» смены типа на ходу, сделать её долгой.
3. ⚠️ Снаряд-сущность на сервере с большим онлайном — нагрузка. Держать
   время жизни снаряда ≤ 3 секунд.
