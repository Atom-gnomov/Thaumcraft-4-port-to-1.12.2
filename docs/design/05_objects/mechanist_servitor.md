# Сервитор Механистов · Mechanist Servitor

| | |
|---|---|
| **Registry** | `unboundtech:mechanist_servitor` |
| **Тип** | сущность (враждебная) |
| **Тир** | T5 (данж) |
| **Акт** | V. Синтез |
| **Статус** | 🔜 спроектировано |
| **Класс** | `unboundtech.common.entities.EntityMechanistServitor` (планируется) |

## 1. Зачем это существует

Закрывает открытый вопрос 3 из `dungeon_and_boss.md`: сервиторы
упоминались и в данже, и в бою с боссом, но карточки не имели.

Их роль — **население Разлома**: механические пауки-охранники, которые
всё ещё выполняют приказ, отданный мёртвым цехом. В бою с Колоссом они
ремонтируют пилоны, то есть превращают «обесточить и добить» в задачу с
сопротивлением.

## 2. Место в мире

- **Кому нужен:** данжу — иначе три яруса пусты; бою — иначе отключение
  пилонов происходит без помех.
- **Что открывает:** ничего; изредка роняют Заряженную Искру.
- **Что требует:** генерацию Разлома.
- **С чем взаимодействует:** пилоны (чинят), техно-духи (не трогают друг
  друга — оба «свои» для комплекса), игрок.
- **Что заменяет/дополняет:** заменяет рад-зомби из архива. Радиация
  позже вернулась в объём как отдельная система (`radiation.md`), но в
  данж не пошла: Разлом населяют машины Механистов, а не бедствие.

## 3. Лор

«Сервитор не охраняет — он **прибирается**. То, что игрок в его глазах
относится к категории беспорядка, говорит не о злобе, а о качестве
исходной описи. Механисты составляли опись в спешке».

## 4. Механика

- **Периодичность:** обычный ИИ моба; особые действия — ниже.
- **Радиус действия / зона:** агрится в **16 блоках**, вне данжа не
  спаунится вовсе.
- **Условия работы:** живёт только внутри структуры Разлома (границы
  структуры проверяются по её `StructureBoundingBox`).
- **Условия отказа:** [N/A].
- **Пределы:**
  - **не спаунится в мире** — только генерацией данжа и вызовом босса;
  - на арене одновременно **не более 6** сервиторов;
  - босс вызывает подкрепление не чаще раза в **15 секунд**.

### 4.1. Поведение

| Ситуация | Что делает |
|---|---|
| Игрок в 16 блоках | Быстро сближается (скорость выше зомби), бьёт током |
| Отключённый пилон рядом (бой с боссом) | **Бросает игрока и идёт чинить**: 5 секунд у пилона возвращают его в строй |
| Игрок в квант/нано-броне | Приоритетная цель: удар по носителю EU-снаряжения **высасывает 2 000 EU** вместо части урона |
| Здоровье < 25 % | Начинает искрить; при смерти — небольшой электрический разряд по 2 блокам вокруг |

Удар током игнорирует **половину** брони. Полный **защитный костюм IC2**
(Hazmat Suit) снижает урон током **вдвое** — награда за знание чужого
мода.

⚠️ Уточнение названия (решение владельца): «резинового комплекта» в IC2
нет как названия, но есть **защитный костюм, который делается из
резины** — это он и есть. Комплект из четырёх предметов:

| Слот | Предмет IC2 |
|---|---|
| Голова | `ic2:hazmat_helmet` (Scuba Helmet) |
| Грудь | `ic2:hazmat_chestplate` |
| Ноги | `ic2:hazmat_leggings` |
| Ботинки | `ic2:rubber_boots` |

Проверка — та же, что везде в моде: `IHazmatLike.hasCompleteHazmat`
(`radiation.md` §7). Отдельного «частичного» бонуса нет: половина
костюма не защищает ни от радиации, ни от сервитора — правило одно на
весь мод.

## 6. Рецепт

- **Верстак:** [N/A] — сущность не крафтится.
- **Появление:** генерация данжа (ярусы 1–3) и вызов боссом.
- **Исследование-владелец:** упоминается в лорной записи о Разломе; ни
  одна запись не гейтится сервитором.

## 7. Аспекты объекта

Сканирование сущности: `Machina 5`, `Bestia 3`, `Metallum 3`,
`Potentia 2`. Это единственный «зверь-машина» в моде, и сочетание
`Bestia` + `Machina` — его подпись, по которой игрок понимает, что перед
ним не голем и не мертвец.

## 8. Визуал

- **Модель:** шестиногий паук из латуни и меди, корпус — перевёрнутая
  чаша, в центре — светящийся глазок-линза.
- **Текстуры:** `entity/mechanist_servitor.png` + эмиссивный слой линзы.
- **Состояния:** цел (линза голубая), повреждён < 25 % (линза красная,
  искрит), чинит пилон (луч от корпуса к пилону).
- **Анимация:** быстрая семенящая походка, дуги электричества между
  ногами при беге; смерть — короткий разряд и осыпающиеся пластины.
- **Как читается силуэт:** ниже игрока, широкий, низкий — читается как
  «уборщик», а не как боец, и это правильное первое впечатление.

## 9. Взаимодействие с игроком

- **ЛКМ / оружие:** обычный бой; хорошо горит.
- **ПКМ:** [N/A] — не приручается, не торгует.
- **GUI:** [N/A].
- **Тултип/статус:** имя над головой не показывается; состояние читается
  по линзе.
- **Гогглы Откровения:** показывают, **какой пилон** сервитор идёт
  чинить, линией — иначе в бою невозможно понять, куда он побежал.

## 10. Крайние случаи

| Ситуация | Поведение |
|---|---|
| Игрок вышел из данжа, сервиторы остались | Возвращаются к точке спауна, не преследуют за границу структуры |
| Чанк с ареной выгружен | Сервиторы деспаунятся; босс вызовет новых |
| Сервитор столкнул игрока в лаву | Обычная физика, никакой особой логики |
| Игрок без EU-снаряжения | Кража EU просто не срабатывает, урон обычный |
| Два сервитора на один пилон | Чинят наперегонки; таймер один, побеждает первый начавший |
| Сервер перезапущен во время ремонта | Таймер ремонта в NBT сущности |
| Мод на автоферму мобов | Сервиторы не спаунятся вне данжа — ферма невозможна по построению |
| Сервитор убит техно-духом | Взаимной агрессии нет; они друг друга не атакуют |

## 11. Приёмка

1. Сервиторы есть на всех трёх ярусах и агрятся в 16 блоках.
2. Удар по игроку в квант-броне списывает 2 000 EU.
3. Полный защитный костюм IC2 (шлем + куртка + штаны + резиновые
   ботинки) вдвое снижает урон током; неполный — не снижает.
4. В бою с боссом отключённый пилон чинится за 5 секунд, если сервитора
   не отогнать.
5. На арене никогда не больше 6 сервиторов.
6. За границей структуры сервиторы не спаунятся и не преследуют.

## 12. Открытые вопросы

1. ❓ Кража 2 000 EU за удар — прикидка. Против квант-брони (10 млн EU)
   это ничто, против ЛапПака — заметно. Возможно, стоит сделать кражу
   **процентной** (0.5 % буфера), чтобы она масштабировалась.
2. ⚠️ Ремонт пилонов может сделать бой бесконечным, если сервиторов
   спаунится больше, чем игрок успевает бить. Лимит 6 и пауза 15 секунд —
   первая защита; проверять в игре.
3. ❓ Стоит ли давать сервиторам **редкий мирный вариант** (чинит машины
   игрока, если его «переписать» на верстаке). Идея на будущее, в объём
   T5 не входит.
