# Фиал-станция · Phial Station

| | |
|---|---|
| **Registry** | `unboundtech:phial_station` |
| **Тип** | блок с тайлом |
| **Тир** | T2 |
| **Акт** | III. Изоляция |
| **Статус** | 🔜 спроектировано |

## 1. Зачем это существует

Ручная возня с фиалами — самая скучная рутина алхимика: наполнить,
опустошить, повторить. Станция делает это за него и служит мостом между
«трубной» эссенцией и «предметной» (фиалами), которые в ТК живут в разных
мирах.

## 2. Место в мире

- **Кому нужен:** магу; технику — как способ вообще потрогать эссенцию.
- **Что требует:** `TEMPERED_THAUMIUM`, источник EU, трубы ТК.
- **С чем взаимодействует:** трубы эссенции, фиалы (`ItemEssence`),
  позже — шина эссенции (`04_systems/essentia_logistics.md`).
- **Что заменяет:** ручной ПКМ фиалом по банке. Банки и трубы не
  вытесняет — станция без них бесполезна.

## 3. Лор

Стеклянная колонна с зажимом и тонкой иглой. Пустой фиал встаёт в гнездо,
игла входит в горлышко, и эссенция сама переливается — ровно восемь единиц,
ни каплей больше. Работает и наоборот, если игле дать обратный ход.
Ничего волшебного в этом нет, и в этом всё дело.

## 4. Механика

Два режима, переключаются **ключом** (`04_systems/machine_feedback.md` §5):

- **Розлив:** объявляет тягу на выбранный аспект, тянет из трубы, копит
  8 единиц, наполняет пустой фиал из входного слота, готовый — в выходной.
- **Слив:** берёт полный фиал, отдаёт 8 единиц в трубу (при наличии тяги
  снаружи), пустой — в выходной слот.

Реализует `IEssentiaTransport` (обязательное правило: всё, что касается
эссенции, — наш блок, `02_world_model.md` §1.2).

**Фильтр аспекта:** ПКМ фиалом по станции задаёт аспект, который она
тянет; пусто = «любой первый пришедший».

## 5. Числа

| Параметр | Значение | Источник |
|---|---|---|
| Ёмкость фиала | 8 единиц | `ItemEssence.PHIAL_AMOUNT` (порт) |
| Внутренний буфер | 8 единиц | ровно один фиал, не склад |
| Цена операции | **200 EU за фиал** | канон §3.4 |
| Скорость | 1 фиал / 2 сек | |
| Буфер EU | 2 000 | 10 операций |
| Слоты | 1 вход, 1 выход | |

## 6. Рецепт

- **Верстак:** арканный.
- **Компоненты:** 4× закалённый таумий, 2× стекло, труба ТК, RE-батарея.
- **Аспекты крафта:** `Ordo 15`, `Aqua 15`, `Machina 10`.
- **Исследование-владелец:** `PHIAL_STATION` (T2), родитель —
  `TEMPERED_THAUMIUM`. Стоимость: `Aqua 10`, `Machina 8`, `Ordo 6`.

## 7. Аспекты объекта

По формуле. Ожидаемо: `Metallum ~8, Machina ~5, Vitreus ~4, Praecantatio ~3`.

## 8. Визуал

- Корпус машины мода + стеклянная колонна спереди, внутри видно фиал.
- Индикаторная полоска (`machine_feedback.md` §2): 🟢 работает,
  🔵 нечего делать, 🔴 нет фиалов / нет EU / нет тяги.
- Анимация: родные частицы вис у иглы в момент переливания (1–2 штуки).

## 9. Взаимодействие с игроком

- **ПКМ пустой рукой:** статус (режим, аспект-фильтр, буфер EU).
- **ПКМ фиалом:** задать аспект-фильтр.
- **ПКМ ключом:** сменить режим.

## 10. Крайние случаи

| Ситуация | Поведение |
|---|---|
| Выходной слот полон | Работа встаёт, 🔴, эссенция остаётся в буфере |
| В трубе другой аспект | При заданном фильтре — не тянет; без фильтра — берёт первый |
| Фиал с чужим аспектом в режиме слива | Отдаёт, если снаружи есть тяга на этот аспект; иначе 🔴 |
| Кончилось EU | Встаёт, ничего не теряется |
| Сломана киркой / ключом | Пусто / с буфером и настройками |

## 11. Приёмка

1. Розлив: труба → фиалы по 8 единиц, 200 EU за штуку.
2. Слив: фиалы → труба, пустые в выход.
3. Фильтр аспекта работает; без фильтра берётся первый пришедший.
4. Полный выходной слот останавливает работу без потерь.
5. Ключ переключает режим, кирка — нет.
