|---|---|
| **Registry** | `unboundtech:ring_frame`, `ring_drive`, `ring_stride`, `ring_brace` |
| **Тип** | предметы (баблсы, слоты колец) |
| **Тир** | T3 |
| **Акт** | IV. Резонанс |
| **Статус** | 🔜 спроектировано |
| **Класс** | `unboundtech.common.items.baubles.ItemSchemaRing` (один класс, четыре метаданных) |

## 1. Зачем это существует

Единственная в моде вещь, которая меняет **самого игрока**, а не его
снаряжение: ванильные атрибуты (`generic.maxHealth` и соседи). Работает с
любой бронёй — алмазной, таумиевой, чужой, нашей — и потому это первый
наш предмет, который полезен ещё до всякой гибридной брони.

## 2. Место в мире

- **Кому нужен:** обоим, и особенно тому, у кого броня чужая.
- **Что открывает:** ничего.
- **Что требует:** `EU_TO_VIS_ENGINE` (T3), закалённый таумий,
  углеволокно.
- **С чем взаимодействует:** Резонансный Амулет (заряжает кольца), наши
  гибридные сеты (питают кольца из своего буфера), рунные кольца ТК
  (**конкурируют за слот**).
- **Что заменяет/дополняет:** ничего не заменяет. Прямая альтернатива
  рунным кольцам ТК: те дают щит, наши — характеристики. Слотов два,
  выбрать можно только одно (`baubles_and_foci.md` §3.3).

## 3. Лор

«Кольцо не колдует. Кольцо **напоминает** телу, каким оно могло бы быть,
если бы его собирали по чертежу, а не как вышло. Тело, как ни странно,
соглашается — пока в кольце есть чем напоминать».

## 4. Механика

### 4.1. Четыре кольца

| Кольцо | Атрибуты (1.12.2) | Смысл |
|---|---|---|
| **Остова** `ring_frame` | `generic.maxHealth` **+4** (2 сердца), `generic.armorToughness` **+1** | Выживание |
| **Привода** `ring_drive` | `generic.attackSpeed` **+0.4**, `generic.attackDamage` **+1** | Ближний бой |
| **Хода** `ring_stride` | `generic.movementSpeed` **+12 %** (операция 2, множитель) | Подвижность |
| **Упора** `ring_brace` | `generic.knockbackResistance` **+0.5**, `generic.armor` **+2** | Держать строй |

Атрибуты вешаются через `getAttributeModifiers` баблса с постоянными
UUID — по одному на кольцо, иначе два одинаковых кольца конфликтуют.

### 4.2. Цена

- **2 EU/тик** на кольцо, пока оно надето и заряжено.
- Буфер **100 000 EU** ⇒ около **42 минут** непрерывной работы (100 000 / 2 EU/t / 20 т/сек / 60).
- Заряд кончился → **атрибуты снимаются**, кольцо остаётся надетым и
  целым; вернулся заряд — атрибуты вернулись. Никаких поломок.
- ⚠️ Снятие `generic.maxHealth` при живом игроке **обязано** проверять
  текущее здоровье: если игрок был на 20 HP из 24, после снятия он должен
  оказаться на 20 из 20, а не умереть. Это классический источник смертей
  «на ровном месте» в модах с бонусным HP.

### 4.3. Синергия с нашими сетами

В полном комплекте **Нано-Таум** или **Квант-Пустотного** кольца тратят
EU **из буфера брони**, а не из своего. **Квант-Ихорный сет исключён:**
его буфер бесконечен и наружу ничего не отдаёт (`quantum_hybrid_armour.md`
§4.3г), иначе кольца работали бы вечно и бесплатно. Свой буфер при этом не расходуется
и служит запасом на случай, когда броня разрядилась.

Для обычной брони кольца работают так же, но заряжать надо каждое
отдельно (или носить Резонансный Амулет, который их заряжает).

- **Периодичность:** списание EU — раз в 20 тиков пачкой по 40 EU
  (дешевле, чем каждый тик).
- **Условия отказа:** нет заряда → атрибуты сняты, тултип красный.
- **Пределы:** **рунного заряда не дают вовсе** (`getRunicCharge` = 0) —
  это и есть плата за атрибуты. Два одинаковых кольца **не складываются**:
  второе не даёт ничего и говорит об этом в тултипе.

## 5. Числа

| Параметр | Значение | Источник |
|---|---|---|
| Расход | **2 EU/t** на кольцо | собственное |
| Буфер | 100 000 EU (**~42 мин**) | собственное |
| Тир зарядки IC2 | LV (32 EU/t) | собственное |
| Рунный заряд | **0** | собственное (плата за атрибуты) |
| `maxHealth` (Остова) | +4 | собственное |
| `armorToughness` (Остова) | +1 | собственное |
| `attackSpeed` (Привода) | +0.4 | собственное |
| `attackDamage` (Привода) | +1 | собственное |
| `movementSpeed` (Хода) | +12 % | собственное |
| `knockbackResistance` (Упора) | +0.5, **суммарно зажато на 1.0** | собственное (у METS Heavy — 1.0 на нагруднике; в Нано-Тауме кольцо не добавит ничего) |
| `armor` (Упора) | +2 | собственное |

⚠️ **Два кольца стоят 4 EU/t — больше, чем даёт Таум-Генератор в
устойчивом темпе (~3.3 EU/t, `02_world_model.md` §3.3).** То есть маг,
надевший пару колец, своим же конвертером их не прокормит: нужна сеть,
солнечная панель или запас. Это осознанно — кольца техническая вещь, — но
игрок должен узнать об этом из тултипа, а не опытным путём.

Ориентир скромности: два кольца дают максимум +4 HP и +2 брони или
+1 урона и +20 % скорости атаки. Это заметно, но не переворачивает бой —
и намеренно слабее, чем 10 очков рунного щита от пары колец ТК в тяжёлом
бою.

## 6. Рецепт

- **Верстак:** арканный (все четыре).
- **Сетка / компоненты:**

```
 T      T — закалённый таумий
CVC     C — углеволокно IC2, V — вис-кристалл нужного примала
 T      (Остова — Terra, Привода — Ignis, Хода — Aer, Упора — Ordo)
```

- **Аспекты крафта:** `Ordo 20`, `Terra 15`, `Aer 10` — **только
  примордиалы** (`02_world_model.md` §6.8).
- **Нестабильность:** [N/A].
- **Исследование-владелец:** `SCHEMA_RINGS` (T3), родитель —
  `EU_TO_VIS_ENGINE`. complexity 2. Стоимость: `Corpus 12`,
  `Machina 12`, `Praecantatio 10` — 3 аспекта, 34 единицы. Одна запись
  выдаёт все четыре кольца.
- **Альт-рецепты при аддонах:** нет.

## 7. Аспекты объекта

По формуле, арканная подпись. Ожидаемый профиль (общий для всех четырёх):
`Metallum ~6, Machina ~4, Praecantatio ~3`, плюс примал своего кристалла.

⚠️ Профиль, а не расчёт — точные числа из лога.

## 8. Визуал

- **Модель:** плоские иконки; на игроке — слой Baubles.
- **Текстуры:** одно кольцо-основа (таумий + углеволокно) с **разной
  вставкой** по типу: землистая, огненная, воздушная, порядковая.
  Цвет вставки = цвет примала ТК, чтобы игрок узнавал без тултипа.
- **Состояния:** вставка светится при заряде, тухнет при нуле.
- **Анимация:** [N/A].
- **Как читается силуэт:** четыре одинаковых кольца с разноцветными
  камнями — читается как «набор», и это правильно.

## 10. Крайние случаи

| Ситуация | Поведение |
|---|---|
| Заряд кончился при полном HP от Кольца Остова | Атрибут снят, текущее здоровье **зажимается** по новому максимуму, смерти не происходит |
| Два одинаковых кольца | Второе не даёт ничего, тултип предупреждает |
| Кольцо Остова + зелье силы/здоровья | Атрибуты складываются по ванильным правилам |
| Смерть с надетыми кольцами | Выпадают с сохранённым зарядом |
| Наша броня разряжена, кольца заряжены | Кольца переходят на свой буфер |
| Baubles не установлен | Кольца не регистрируются |
| Чужой мод меняет те же атрибуты | Конфликта нет: у нас свои UUID модификаторов |
| Сервер перезапущен | Заряд в NBT; атрибуты навешиваются заново при надевании |

## 11. Приёмка

1. Надеть Кольцо Остова → +2 сердца в интерфейсе.
2. Разрядить его при неполном здоровье → сердца ушли, игрок жив.
3. Кольцо Хода → скорость выросла примерно на 12 %.
4. Кольцо Привода → полоска замаха заполняется быстрее.
5. Два Кольца Остова → бонус один.
6. Надеть в полном Нано-Тауме → EU тратится из брони, буфер кольца цел.
7. Проверить, что рунный щит от колец не растёт.
8. ~42 минуты работы от полного буфера (проверить на ускоренном тике).

## 12. Открытые вопросы

1. ❓ 2 EU/t на кольцо — прикидка (следствие расписано в §5). Проверить в
   игре: если пара колец делает Таум-Генератор бессмысленным как источник
   для мага, снизить до 1 EU/t.
2. ⚠️ `generic.maxHealth` — самый опасный атрибут в модах: любая ошибка
   в порядке снятия/навешивания даёт смерть при выходе из игры или смене
   измерения. При реализации это первое, что надо протестировать.
3. ❓ Стоит ли делать пятое кольцо на `generic.luck` (влияет на лут).
   Заманчиво, но лут-таблицы — не наша территория; пока нет.
