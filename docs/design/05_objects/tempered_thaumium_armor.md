# Броня из закалённого таумия · Tempered Thaumium Armor

| | |
|---|---|
| **Registry** | `unboundtech:tempered_helmet` / `_chestplate` / `_leggings` / `_boots` |
| **Тип** | броня (4 элемента) |
| **Тир** | T2–T3 |
| **Акт** | III. Изоляция |
| **Статус** | 🔜 спроектировано |

## 1. Зачем это существует

Ранняя броня инженера-тауматурга: её можно **сковать**, а не наполнить на
алтаре. Она перекрывает разрыв между «железо» и высокими сетами (T4+),
и делает это честно — платя за доступность магической неуклюжестью.

Дизайнерская роль: показать игроку, что кузнечный путь к магической броне
существует, но у него есть цена. Это подготавливает восприятие гибридных
сетов T4, где цена уже другая.

## 2. Место в мире

- **Кому нужен:** обоим; особенно технику, у которого ещё нет доступа к
  инфузии.
- **Что требует:** `TEMPERED_THAUMIUM` (материал) + свой рецепт-исследование.
- **Что открывает:** ничего механически; служит основой для вставки
  гогглов (`machine_feedback.md` §6.3).
- **С чем взаимодействует:** система гогглов ТК, скидки на вис
  (`IVisDiscountGear`), зачарование.

## 3. Лор

Крепостной доспех куют на алтаре, и вис сам укладывает пластины так, как
им следует лежать. Закалённый таумий этого не позволяет: его форма задана
домной, а не волей. Кузнец бьёт молотом там, где тауматург просто
пожелал бы — и результат виден, стоит взять доспех в руки. Он груб.
Пластины толще, стыки заметны, руны легли криво и держат вис хуже, чем
могли бы.

Зато его можно надеть на второй день после того, как заработала домна.

## 4. Механика

- **Защита:** уровень алмаза, **×1.2** по значениям (см. §5).
  Обоснование: материал прочнее стали и держит удар лучше алмаза, но не
  благодаря магии, а благодаря плотности.
- **Штраф зачарования:** очень низкая `enchantability` — на столе
  зачарований выпадают короткие и слабые списки. Обоснование: выгоревшая
  магическая решётка плохо принимает чужие чары.
- **Штраф вис:** реализуем `IVisDiscountGear` с **отрицательным** значением
  — носитель тратит вис **больше** обычного. Это родной API ТК, никаких
  хаков; отрицательная «скидка» и есть штраф.
- **Гогглы:** вставляются, но дороже (×1.5 материалов) —
  `machine_feedback.md` §6.3.

## 5. Числа

| Параметр | Значение | Комментарий |
|---|---|---|
| Броня (шлем/нагрудник/поножи/ботинки) | 4 / 10 / 7 / 3 | алмаз ×1.2, округление вниз от 3/8/6/3 |
| Прочность (durability multiplier) | 30 | между железом (15) и алмазом (33) |
| Enchantability | **6** | железо 9, алмаз 10, золото 25 → мы ниже железа |
| Toughness | 1.0 | половина алмазной (2.0) |
| Штраф вис | **−5% за элемент** (−20% за сет) | через `IVisDiscountGear` |
| Материал починки | `ingotTemperedThaumium` | |

Сравнение для честности: полный сет даёт защиты чуть больше алмазного, но
маг в нём кастует на 20% дороже — то есть тауматургу он **невыгоден**,
пока тот не решает задачу выживания. Это и есть заявленный компромисс.

## 6. Рецепт

- **Верстак:** обычный (принципиально! — это кузнечная броня).
- **Сетка:** стандартная броневая раскладка из `ingotTemperedThaumium`.
- **Больше материала, чем у аналогов:** ❓ **НЕ РЕШЕНО, требуется решение
  владельца.** Обычная сетка брони в Minecraft жёсткая (5/8/7/4 слитка) и
  «больше» в неё не вписать без ухода в нестандартный рецепт.
  Два варианта:
  - **(а)** оставить стандартную сетку, а «дороже» выразить через сам
    материал (два передела: домна + тигель) — просто, ничего не ломает;
  - **(б)** сделать двухступенчатый крафт: сначала «грубая пластина»
    (2 слитка → 1 пластина), из пластин — броня; тогда сет стоит вдвое
    больше слитков и визуально объясняет «толстые пластины» из лора.
  **Рекомендация: (б)** — она же даёт материал для будущих корпусов.
- **Исследование-владелец:** `TEMPERED_ARMOR` (T2–T3), стоимость
  `Metallum 15`, `Tutamen 12`, `Praecantatio 6`, `Ignis 4`.

## 7. Аспекты объекта

По формуле (`aspect_economy.md`), нагрудник из 8 слитков
(`Metallum 5, Praecantatio 5, Ignis 3` каждый):
- сумма ≈ `Metallum 40, Praecantatio 40, Ignis 24` → ×0.6 →
  `Metallum 24, Praecantatio 24, Ignis 14`;
- подпись верстака: `Fabrico +2`, `Praecantatio +2`;
- нормализация до 40 (§2.5): пропорционально ужимаем.
- **Итог (нагрудник):** ≈ `Metallum 15, Praecantatio 15, Ignis 8, Tutamen 2`.

## 8. Визуал

- **База:** текстура **Крепостного доспеха** (`fortress_armor.png`) из
  порта, переработанная в «грубую» версию:
  - пластины толще, границы между ними резче;
  - руны присутствуют, но **прерывистые** — часть линий не сомкнута;
  - палитра: холодный серый вместо таумиевого лилового, редкие фиолетовые
    вкрапления в тех же местах, где у слитка;
  - никакого свечения (у крепостной брони оно есть) — это главный
    визуальный маркер «магия выгорела».
- **Файлы:** `models/tempered_armor_1.png`, `_2.png` (слои 1.12.2).
- **Иконки предметов:** силуэт крепостного доспеха, но «квадратнее».
- **Анимация:** нет.
- **Как читается:** рядом с крепостным доспехом — очевидно «то же, но
  кованое кое-как». Это ровно тот месседж, который нужен.

## 9. Взаимодействие с игроком

- **Тултип:** обязательно показывать штраф вис (иначе игрок сочтёт баг),
  формулировкой из ТК-стиля: «Расход вис увеличен на 20%».
- **Гогглы:** после вставки шлем показывает узлы и подсказки; EU-строки —
  по `machine_feedback.md` §6.2.

## 10. Крайние случаи

| Ситуация | Поведение |
|---|---|
| Игрок в полном сете колдует | Расход вис +20%, тултип жезла показывает итог с учётом штрафа |
| Сет + другая скидочная броня | Скидки суммируются алгебраически (родное поведение `IVisDiscountGear`) |
| Зачарование через инфузию (а не стол) | Работает нормально — штраф только у стола зачарований |
| Починка | Только `ingotTemperedThaumium` |
| Шлем с гогглами + шлем без | Разные предметы, не взаимозаменяемы при починке |

## 11. Приёмка

1. Значения защиты соответствуют §5, тултип показывает штраф вис.
2. На столе зачарований списки заметно беднее, чем у железа.
3. Каст с полным сетом стоит на 20% дороже (замерить по жезлу).
4. Гогглы вставляются, стоят в 1.5 раза дороже, чем в таумиевый шлем.
5. Визуально отличима от крепостного доспеха на расстоянии.

## 12. Открытые вопросы

   окажется сильнее, чем задумано (алмаз и так топ до T4).
3. ❓ Делать ли из материала инструменты (кирка/топор) — или инструменты

   потому что закрывает нишу «магическая защита без алтаря»; инструменты
   такой ниши не закрывают. **Предложение: инструменты не делать.**
