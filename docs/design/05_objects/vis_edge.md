# Вис-Кромка · Vis Edge

| | |
|---|---|
| **Registry** | `unboundtech:vis_edge` (предмет-надстройка) + NBT-тег `UTVisEdge` на клинке |
| **Тип** | предмет (модификатор чужого оружия) |
| **Тир** | T4 |
| **Акт** | IV. Резонанс |
| **Статус** | 🔜 спроектировано |
| **Класс** | `unboundtech.common.items.ItemVisEdge` + обработчик события урона |

## 1. Зачем это существует

Ответ на «продлить идею нано-сабли IC2 и квантовой катаны METS», не делая
своего энергетического меча. Мы не добавляем цифру к чужому оружию — мы
меняем **форму** его урона: часть приходит не сразу.

## 2. Место в мире

- **Кому нужен:** технику, у которого уже есть энергетический клинок и
  которому нечего с ним делать дальше.
- **Что открывает:** ничего.
- **Что требует:** `FLUX_ARQUEBUS` (T4), вис-кристаллы, нано-саблю IC2
  или катану METS.
- **С чем взаимодействует:** `IElectricItem`-клинки чужих модов.
- **Что заменяет/дополняет:** дополняет чужое оружие. Своего клинка мы не
  делаем принципиально (`ranged_weapons.md` §4.8).

## 3. Лор

«Хороший удар заканчивается, когда клинок вышел. Вис-кромка не согласна:
она оставляет в ране кусок незавершённого действия, и рана продолжает
происходить сама. Мастера говорят, что это невежливо. Мастера, впрочем,
не дрались с тем, ради чего кромку придумали».

## 4. Механика

### 4.1. Установка

- Обычный верстак: **клинок + Вис-Кромка** → тот же клинок с тегом
  `UTVisEdge`. Предмет-кромка расходуется.
- Принимаются: предметы, реализующие `IElectricItem` **и** являющиеся
  оружием ближнего боя (`ATTACK_DAMAGE` в `getAttributeModifiers`).
  На практике это нано-сабля IC2 и катаны METS.
- **Не принимаются:** ихорий и Ихоро-Иридиевый Клинок
  (`ichor_iridium_blade.md` §4.3), обычные мечи без заряда, аркебуза.
- Снимается ключом: тег удаляется, **кромка не возвращается**.

### 4.2. Отложенный урон

Попадание клинком с кромкой ставит на цель эффект «Резонанс»:

| Момент | Что происходит |
|---|---|
| 0 сек | обычный урон клинка (мы его не трогаем) |
| **+2 сек** | **20** урона «доигрывания» — магический тип, броня учитывается наполовину |
| **+4 сек** | **10** урона догорания + поджиг на 2 сек |

- **Стек не складывается:** повторное попадание **обновляет таймер**, а
  не заводит второй. Три удара за секунду дают те же 30 отложенного, а не
  90 — это главное ограничение и его надо проверять в первую очередь.
- Эффект **не по площади**: только по цели, в которую попали.
- Если цель умерла до срабатывания — ничего не переносится.
- Расход заряда клинка: **+200 EU за удар** сверх обычного. Кромка не
  бесплатна, и разряженный клинок её не применяет.

**Ниша.** Против одиночной крупной цели 30 отложенного — много. Против
толпы — почти бесполезно (стек не складывается, площадей нет). Ровно та
форма, которой у чужих клинков нет.

## 5. Числа

| Параметр | Значение | Источник |
|---|---|---|
| Доигрывание | **20** через 2 сек | решение владельца |
| Догорание | **10** через 4 сек + поджиг 2 сек | там же |
| Стек | не складывается, таймер обновляется | `ranged_weapons.md` §4.7 |
| Расход клинка | +200 EU за удар | собственное |
| Тип урона | магический, броня ×0.5 | собственное |

## 6. Рецепт

- **Верстак:** матрица инфузии (предмет-кромка), затем обычный верстак
  (установка на клинок).
- **Центральный предмет:** углеволоконная пластина IC2.
- **Пьедесталы:** вис-кристалл `Perditio`, вис-кристалл `Ignis`,
  закалённый таумий, кристалл ТК любой.
- **Аспекты инфузии:** `Telum 24`, `Perditio 20`, `Praecantatio 16`,
  `Ignis 12`.
- **Нестабильность:** **5**.
- **Исследование-владелец:** `VIS_EDGE` (T4), родитель — `FLUX_ARQUEBUS`.
  complexity 3. Стоимость: `Telum 14`, `Perditio 12`, `Praecantatio 12`,
  `Ignis 8` — 4 аспекта, 46 единиц.
- **Альт-рецепты при аддонах:** **если METS не установлен** — работает с
  нано-саблей IC2; если и её нет — **рецепт не регистрируется вовсе**
  (объекта в игре не появляется).

## 7. Аспекты объекта

По формуле, инфузионная подпись. Ожидаемый профиль:
`Telum ~10, Perditio ~8, Praecantatio ~6, Metallum ~4`.

⚠️ Профиль, а не расчёт — точные числа из лога.

## 8. Визуал

- **Модель:** сам предмет — тонкая полоса металла с фиолетовой кромкой.
- **Текстуры:** `items/vis_edge.png`; на клинке — **накладной слой**
  свечения кромки поверх чужой модели (не заменяем чужую текстуру!).
- **Состояния:** на цели с эффектом «Резонанс» — фиолетовые частицы,
  учащающиеся к моменту срабатывания. Игрок должен видеть таймер глазами.
- **Анимация:** в момент доигрывания — короткая вспышка и звук
  `thaumcraft:wand`.
- **Как читается силуэт:** чужой клинок с фиолетовой кромкой — понятно,
  что это чужое оружие с нашей надстройкой.

## 9. Взаимодействие с игроком

- **ЛКМ клинком:** обычный удар + постановка эффекта.
- **Shift-ПКМ ключом по клинку:** снять кромку (расходуется безвозвратно).
- **GUI:** [N/A].
- **Тултип клинка:** «Вис-Кромка: 20 через 2 сек, 10 через 4 сек. Не
  складывается».
- **Гогглы:** показывают оставшееся время «Резонанса» над целью.

## 10. Крайние случаи

| Ситуация | Поведение |
|---|---|
| Цель умерла до срабатывания | Эффект пропадает, ничего не переносится |
| Цель сменила измерение | Эффект снимается (таймер привязан к сущности в мире) |
| Игрок вышел из игры | Урон всё равно сработает: эффект живёт на цели, не на игроке |
| Попадание по игроку в PvP | Работает симметрично; в тултипе сказано |
| Клинок разряжен | Кромка молчит, обычный удар проходит |
| Мод клинка обновился и сменил класс | Тег на NBT переживает: мы не привязаны к классу, только к интерфейсу |
| Кромка на клинке, который сломался | Теряется вместе с ним |
| Два игрока бьют одну цель разными клинками с кромкой | Таймер один, обновляет последний попавший; урон получает автор последнего удара |

## 11. Приёмка

1. Поставить на нано-саблю → тултип изменился, кромка светится.
2. Ударить моба с 60 HP → 0 сек обычный урон, +2 сек −20, +4 сек −10.
3. Ударить трижды за секунду → суммарно всё те же 30 отложенного.
4. Разрядить саблю → отложенного урона нет.
5. Снять ключом → тег ушёл, кромка не вернулась.
6. Проверить без METS: рецепт есть; без METS и без IC2-сабли: рецепта нет.

## 12. Открытые вопросы

1. ⚠️ 30 отложенного урона — **много**: нано-сабля бьёт ~20 при заряде.
   Мерить против неё и катан METS; если кромка удваивает DPS одиночной
   цели, снижать догорание, а не доигрывание (владелец назвал именно
   20 и 10, и первое число трогать нельзя без его слова).
2. ❓ Броня ×0.5 на отложенном уроне — наше добавление к решению
   владельца. Если окажется, что против брони T5 эффект теряется совсем,
   сделать урон чистым (`DamageSource.MAGIC` без брони).
3. ❓ Показывать ли таймер «Резонанса» в HUD цели без гогглов. Пока нет:
   частиц достаточно.
