## 3. Правила, которые легко забыть

- **Арканный верстак платит вис из жезла ⇒ в стоимости арканного рецепта
  только шесть прималов.** Составной аспект там — ошибка
  (`02_world_model.md` §6.8).
- **Аспекты назначения** (`Telum`, `Instrumentum`, `Tutamen`…) движок
  дописывает **только по классу предмета**. Наши стволы не наследуют
  `ItemSword`/`ItemBow`, поэтому `Telum` им пишем руками; всему, что
  попадает в известные классы, — не пишем (`aspect_economy.md` §2.6).
- **`merge` в `AspectList` — это максимум, а не сложение.** Ручное
  значение не удваивается, а тихо перебивает вычисленное.
- **`IGoggles`/`IRevealer` читаются только в слоте шлема.**
- **Любая наша машина, берущая вис из сети ТК, обязана считать пол в 20 %
  сама** — у `VisNetHandler.drainVis` его нет. Пока таких машин **ноль**:
  Патронная Линия решением владельца переведена на чистое электричество.
- **Потолок нестабильности — 15** (максимум во всей ТК4, продвинутые
  KAMI-инструменты). Выше не поднимаемся никогда.
- SRP заморожен; работа идёт только в сабветке, не в `main`.
