## 4. Код T2 — заблокирован средой, не дизайном

Владелец решил: следующий шаг — реализация T2 (закалённый таумий, броня,
инструменты, ключ, электрочернильница, фиал-станция, эссент-горелка).

**В этой среде собрать нельзя, проверено:**

| Хост | Статус |
|---|---|
| `maven.minecraftforge.net` | заблокирован прокси |
| `files.minecraftforge.net` | заблокирован |
| `www.cursemaven.com` | заблокирован |
| `repo1.maven.org` | доступен (толку мало) |

Кэш Gradle пуст, Forge/MCP/IC2/Baubles не скачать; в `libs/` сабмода нет
dev-jar порта. JDK 8 на месте (`/usr/lib/jvm/java-8-openjdk-amd64`), но
собирать нечем. Владелец сказал, что перенесёт код сам, когда будет среда
со сборкой.

Что **можно** делать здесь без компилятора и что уже подготовлено:

- исходники API IC2 распакованы для сверки сигнатур:
  `<scratch>/ic2api_src/ic2/api` (127 файлов `.java`);
- dev-jar IC2 для `javap`: `<scratch>/mets/libs/industrialcraft-2-2.8.195-ex112-dev.jar`;
- исходники METS и ASP, распакованный IC2Additions (только идеи — он
  несовместим с METS/ASP и в сборке его не будет);
- полный исходник порта TC4U — главный источник правды по API Thaumcraft.

То есть код писать можно, проверяя каждую сигнатуру по исходникам; нельзя
только доказать компиляцией.
