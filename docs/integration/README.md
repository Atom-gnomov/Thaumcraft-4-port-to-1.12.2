# Интеграция: Thaumcraft 4 (порт 1.12.2) + IC2 (+ SRP)

Папка с дизайн-документами интеграции. Документы наслаиваются итерациями:
**v1** (GDD, 4 части) → **v2** (дерево исследований) → **v3** (логическая
доработка IC2↔TC) → **v4** (сабмод, броня-сплавы, сущности, пайплайны) →
**v5** (финальные вердикты, оружие, данж, радиация, инфо-каркас).

При противоречии между версиями **приоритет у более поздней** (v5 > v4 > v3 > v2 > v1).
Интеграция реализуется **отдельным сабмодом Unbound Technology**
(modid `unboundtech`), а не внутри TC4 Unbound — `ic2_v4_submod.md`,
`ic2_v5_decisions.md`.

## Статус реализации

В коде интеграции IC2 пока **нет** — все документы являются проектом.
Реализация пойдёт в **отдельном репозитории/модуле сабмода** (см.
`ic2_v4_submod.md`), TC4 Unbound при необходимости получит только
API-хуки (события ауры/флюкса, регистрация компонентов жезлов извне).
Порядок работ MVP — `ic2_v3_items.md` §7.
