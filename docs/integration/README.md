# Интеграция: Thaumcraft 4 (порт 1.12.2) + IC2 (+ SRP)

Папка с дизайн-документами интеграции. Документы наслаиваются итерациями:
**v1** (GDD, 4 части) → **v2** (дерево исследований) → **v3** (логическая доработка IC2↔TC).

При противоречии между версиями **приоритет у v3** — см. `ic2_v3_audit.md`.

## Порядок чтения для нового участника

1. `ic2_srp_design_part1_lore.md` — общий замысел.
2. `ic2_v3_principles.md` — правила, на которых всё держится.
3. `ic2_v3_machines.md` и `ic2_v3_items.md` — что конкретно делаем.
4. `rt_1_ic2.md` … `rt_4_synthesis.md` — как это лежит в Таумономиконе.
5. `ic2_v3_audit.md` — почему v3 местами расходится с v1/v2.

## Статус реализации

В коде мода интеграции IC2 пока **нет** (ни compat-модуля, ни рецептов) —
все документы здесь являются проектом. Точка входа для реализации:
compat-модуль по образцу существующих шимов, за `Loader.isModLoaded("ic2")`.
