# Арт-гайд Unbound Technology: форматы, стиль, пайплайн
## Ответ на вопрос «текстуры будут в адекватном формате и стиле?» — да, вот правила.

Гайд привязан к фактическим ассетам порта (`mod/src/main/resources/assets/thaumcraft/textures/`).

---

## 1. Форматы (технический канон, совпадает с TC4U и IC2)

| Тип | Формат | Прецедент в порте |
|---|---|---|
| Предметы | PNG 16×16, RGBA | `items/alumentum.png` (16×16 RGBA) |
| Блоки | PNG 16×16 (RGB/RGBA) | `blocks/*.png` |
| Анимация | PNG-полоса + `.png.mcmeta` | `items/bath_salts.png.mcmeta` |
| Машины со состояниями | отдельные `_on`/`_off` текстуры | `models/alch_furnace.png` / `alch_furnace_on.png` |
| Броня (ванильные слои) | 64×32 `layer_1`/`layer_2` | стандарт MC 1.12.2 |
| Броня (кастомные модели) | до 256×128 | `models/fortress_armor.png`, `cultist_*_armor.png` |
| Оверлеи брони | отдельный PNG с прозрачностью | `models/void_robe_armor_overlay.png` — **готовый прецедент для наших гибридов** |
| GUI | 256×256 | `gui/*` |
| Иконка вкладки Таумономикона | 16×16 | `misc/` (по образцу r_* иконок) |

Выводы: ничего экзотического не нужно — разрешение 16×16 у обоих модов-родителей,
слоёная броня уже поддержана кодом порта (void robe + overlay), эмиссив делаем
тем же приёмом «второй слой» + fullbright-рендер (armor doc §4).

## 2. Стиль (визуальный канон)

**База — стиль TC4** (мягкие тени, «пыльная» палитра, лёгкий шум), потому что
мод живёт в Таумономиконе и рядом с ТК-блоками. IC2-элементы цитируются
узнаваемыми деталями, а не своим плоским стилем целиком.

Палитра (собрать `palette.png` из ассетов, опорные группы):
- **Таум-пурпур** (таумий, руны, вис) — фиолетовые из `items/*` ТК.
- **Латунь/золото Механистов** — тёплые металлы ТК (жезлы, котёл).
- **Машинные серые IC2** — 3–4 серых тона (advanced machine casing).
- **Акценты**: вольт-жёлтый (EU, искры), рад-зелёный (свечение), флюкс-лиловый.

Правила гибридных предметов/блоков (главное!):
1. **Силуэт от родителя-базы, акценты от второго родителя.** Гибридная броня =
   силуэт IC2-сета + таум-пластины/руны поверх; таум-сталь = слиток ТК-формы
   с холодным IC2-отблеском.
2. Один предмет = максимум 2 группы палитры + 1 акцент. Не мешать всё сразу.
3. Читаемость в инвентаре важнее деталей: предмет узнаваем при 100% зуме
   на тёмном и светлом фоне.
4. Свечение (эмиссив, руны, EU-заряд) — всегда отдельным слоем/файлом,
   не запечённым в базу: даёт вкл/выкл-состояния бесплатно.
5. Машины: грани по IC2-паттерну (рамка-корпус + центральная «морда»),
   но корпус — из нашей таум-стали (серый с лёгким пурпурным отливом),
   чтобы блоки Unbound Technology отличались от родных IC2 с одного взгляда.

## 4. Пайплайн работы

1. Инструменты: Aseprite / LibreSprite / Piskel (что удобнее художнику).
2. Первый шаг — `palette.png`: выдернуть цвета из 6–8 эталонных текстур
   (таумий-слиток, жезл, котёл; advanced casing, кабель, генератор IC2)
   и работать только из неё. Палитра коммитится в репо как референс.
3. Для гибридной брони: взять официальные layer-текстуры IC2 как подложку
   на отдельном слое редактора (НЕ включать в наш файл — только референс
   позы/силуэта), рисовать свои слои поверх; в релиз идут только наши PNG.
   Никакого копирования чужих пикселей в наши ассеты — стиль цитируем,
   пиксели рисуем свои (лицензионная гигиена).
4. Каждому блоку с состояниями сразу рисовать обе версии (`_on`/`_off`) —
   дешевле, чем возвращаться.
5. Плейсхолдеры на время разработки: однотонная заливка группы палитры
   с буквой — играбельно, и сразу видно, что не дорисовано.

## 5. Модели (JSON 1.12.2)

- Предметы: `item/generated` (1 слой) или `item/handheld` (пика, аркебуза).
- Машины: `block/orientable`/`cube` + blockstate-варианты `facing`+`active`.
- Мультиблок-печь 3×3×3: контроллер — обычный куб с «мордой»; заполненная
  структура подсвечивается частицами, не спец-моделью (дёшево и в стиле ТК).
- Пика/аркебуза от первого лица: обычные `handheld` json-модели; кастомные
  obj — только если после теста в руке будет выглядеть плохо (в порте obj
  поддержаны — `models/adv_alch_furnace.obj` — но это дорогой путь).
