# v4 | Броня: сплавы сетов и два пути эндгейма
## Заменяет линейную цепочку v1 (Нано-Таум → Пустотный Квант → Ихоровый Квант)

---

## 1. Идея: броня = сплав двух сетов

Каждый гибридный сет крафтится из **готового элемента брони IC2 + готового
элемента брони ТК** (+ связующие материалы). Игрок буквально сплавляет два
комплекта, и это видно в текстуре (§4).

```
        [Крепостная броня ТК]   [Нано-броня IC2]
                 └───────┬───────┘
              НАНО-ТАУМ БОЕВОЙ СЕТ (тир 3)
                         │
        ┌────────────────┴────────────────┐
   путь А (дешевле)                 путь Б (дороже)
        │                                 │
 [Пустотная броня ТК]              [части Ихора KAMI]
   + [Квант IC2]                     + [Квант IC2]
        │                                 │
 КВАНТ-ПУСТОТНЫЙ СЕТ              КВАНТ-ИХОРНЫЙ СЕТ
```

Оба пути — легитимный эндгейм. Путь А достижим без Thaumic Tinkerer,
путь Б требует модуль `kami` и полную ветку Ихория.

---

## 2. Нано-Таум Боевой сет (тир 3)

- **Крафт (за элемент):** Матрица Наполнения — элемент Нано-брони IC2 +
  элемент Крепостной брони ТК (таумиевой) + 2× Таум-Углеродная Ткань +
  2× Вис-Кристалл. Аспекты как в v1 `part4` §1.
- **Свойства:** защита нано-брони; ёмкость 1M EU/элемент; скидка вис 2%/элемент
  (8% сет); зачаровываемость 25; **бонус крепостной**: сет-бонус «Стойкость» —
  −20% отбрасывание и урон от взрывов (наследие крепостной брони).
- Шлем: вариант с интегрированными гогглами (крафт с Гогглами Откровения,
  сохраняет их функции + показ EU из v3).

Примечание: берём именно **Крепостную** (боевую пластинчатую) броню ТК,
а не робы тауматурга — робы остаются «магическим» путём с их скидками на вис;
гибрид — путь «боевого инженера».

---

## 3. Два пути эндгейма

### Путь А — Квант-Пустотный сет («выносливость»)
- **Крафт (за элемент):** элемент Кванта IC2 + элемент Пустотной брони ТК +
  2× Пустотный Иридий + 1× Глаз Древних.
- **Роль:** танк на длинной дистанции, дешёвое обслуживание.
  - Самопочинка пустотного металла (без EU!) + лечение носителя за EU (100 EU/сек → 1 HP/сек).
  - Анти-паразит свойства (модуль `srp`), иммунитет к пробитию брони.
  - Цена пути: +1 Warp за элемент (перманентно, пока надет).
- Слабости: нет полёта, скидка вис меньше (16% сет), не снимает Warp.

### Путь Б — Квант-Ихорный сет («могущество»)
- **Крафт (за элемент):** элемент Кванта IC2 + Ихоровая подкладка
  (Ichorcloth) ×2 + пластина Ихория + 1× Великий Кристалл Завесы.
  Экстремальная инфузия (нестабильность 20+).
- **Роль:** параллель обычной ихорной брони TT, но по-инженерному:
  - Креативный полёт, бесконечная EU-ёмкость (Ихор-генератор внутри).
  - Полный иммунитет к Искажению и эффектам паразитов; скидка вис 24% сет.
  - НЕ имеет самопочинки пустотного металла и +Warp не даёт.
- **Мостик между путями:** элемент Квант-Пустотного можно *переплавить* в
  Квант-Ихорный (инфузия: элемент пути А + ихоровые части, скидка ~30%
  материалов против крафта с нуля). Обратной переплавки нет.

Балансовая рамка: путь Б строго дороже (KAMI + нестабильность 20+), но и
строго сильнее; путь А остаётся лучшим «постоянным» сетом против паразитов
из-за бесплатной самопочинки — не мусор после появления Б.

## 4. Текстуры и визуальный язык (важно!)

Принцип: **гибрид читается с одного взгляда** — видно оба родительских сета.

| Сет | База силуэта | Накладные элементы |
|---|---|---|
| Нано-Таум Боевой | нано-броня (чёрный/жёлтый) | таумиевые пластины поверх (фиолетовый металл), руны на нагруднике, окантовка крепостной брони на наплечниках |
| Квант-Пустотный | квант (белый/голубой) | пластины пустотного металла (тёмно-фиолетовые, «дышащая» тьма), эмиссивные лиловые швы |
| Квант-Ихорный | квант | золотая ихорная филигрань поверх корпуса, эмиссивное золотое свечение (параллель Ichorcloth), «жидкие» подтёки ихора на стыках |

Реализация на 1.12.2 (пометки):
- Два слоя armor layer texture: базовый слой = перекрашенная база IC2,
  верхний слой = наши накладки (отдельный PNG, прозрачный фон).
- Эмиссив — через отдельный RenderLayer с fullbright (как глаза пауков);
  для ихора — анимированная texture (mcmeta, 4–8 кадров медленного пульса).
- Иконки предметов: элемент брони IC2 с видимым «наростом» ТК-материала,
  чтобы в инвентаре гибрид отличался мгновенно.

## 5. Линейка гогглов (адаптировано из EMT — самая любимая фича того аддона)

| Тир | Название | База | Свойства |
|---|---|---|---|
| 2 | Электро-Гогглы Откровения | гогглы + схема + батарея | функции гогглов + показ EU машин; заряд 100k EU — питает ночное зрение |
| 3 | Нано-Гогглы Откровения | гогглы + нано-шлем | + защита нано-шлема, 1M EU |
| 4 | Квант-Гогглы Откровения | гогглы + квант-шлем | + все функции квант-шлема (дыхание, ночное зрение, еда) |
| 4+ | Солнечные Гогглы (модуль `asp`) | квант-гогглы + солнечный шлем ASP | самозарядка + зарядка жезла днём |

Гогглы-линейка не конфликтует со шлемами гибридных сетов: шлем сета можно
скрафтить «с гогглами внутри» (см. §2), тогда линейка гогглов — путь для тех,
кто носит чужой сет.
