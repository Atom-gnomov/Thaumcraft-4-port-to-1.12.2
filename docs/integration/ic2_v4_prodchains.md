# v4 | Производственные цепочки: новые механизмы
## Проблема: в ТК4 «пайплайн» — это одна Адская печь. Даём магу цепочки уровня IC2.

---

## 1. Целевые цепочки (обзор)

```
РУДЫ:      Дробитель IC2 → Эссент-Промыватель → Адская печь / Печь 5×5×5
ЭССЕНЦИЯ:  Электротигель → трубы → Термальная центрифуга (v3) → Фасовщик (v3) → склад
ФЛЮКС:     Аура/операции → Флюкс-Скруббер → Флюкс-конденсат → Генератор / центрифуга
ИНФУЗИЯ:   МФЭ → Матричный Стабилизатор → безопасные инфузии на потоке
```

Четыре новых блока (§2–§5), каждый закрывает один разрыв. Всё — тир 2–3,
середина игры, где v3-аудит фиксировал провал (П-7).

---

## 2. Эссент-Промыватель (Essentia Ore Washer) — тир 2

Аналог рудопромывочной IC2, но моет **эссенцией Aqua** вместо воды.

- **Вход:** измельчённая руда (IC2 crushed ore, включая руды ТК) + 2 ед. Aqua + 500 EU.
- **Выход:** очищенная руда + **аспектный осадок** (новый предмет) +
  для руд ТК шанс 15% на осколок соответствующего аспекта.
- **Аспектный осадок:** плавится в тигле в 1–2 ед. случайных аспектов руды;
  или сжигается в Генераторе (2,000 EU) — выбор: магия или энергия.
- Итог цепочки для руд ТК: Дробитель (×2) → Промыватель (+15% осколок) →
  Печь 5×5×5 (25% дублирование) — сопоставимо с полной цепочкой IC2 по железу,
  но своя, магическая.

## 3. Электротигель (Powered Crucible) — тир 3

Главный QoL-блок для мага. Автоматизирует тигель.

- Греется EU (нет нужды в лаве/ниторе): 20 EU/t в работе.
- Принимает предметы хоппером/трубами, выдаёт эссенцию в трубы ТК.
- Плавит с **−10% потерь** против ручного тигля (стабильный нагрев).
- Переполнение не выбрасывает флюкс в ауру, а копит **флюкс-газ во внутреннем
  баке** (10 ед.) → выводится только через Флюкс-Скруббер (§4). Бак полон →
  тигель останавливается (безопасность вместо загрязнения).
- Ограничение: не выполняет рецепты, требующие взаимодействия игрока
  (клик предметом) — только переплавка в эссенцию.

## 4. Флюкс-Скруббер (Flux Scrubber) — тир 3

Индустриальный ответ на флюкс — то, чего в ТК4 не хватало всегда.

- Тянет флюкс из ауры чанка (1 ед./10 сек) и из бака Электротигля.
- Цена: 400 EU за 1 ед. флюкса.
- **Выход: Флюкс-конденсат** (предмет):
  - сжечь в Генераторе: 4,000 EU («грязная энергия», как скрап-топливо);
  - прокрутить в Термальной центрифуге: 1–2 ед. случайной первичной эссенции;
  - 9 шт. → блок конденсата (декор: «загустевшая скверна», светится).
- Баланс-петля проверена: 400 EU затрат → 4,000 EU выхода, но источник
  ограничен реальным загрязнением — это уборка, а не генератор. Флюкса нет —
  скруббер простаивает.

## 5. Матричный Стабилизатор (Matrix Stabilizer) — тир 3

- Ставится в 4 блоках от Матрицы Наполнения (до 4 шт. на матрицу).
- Каждое событие нестабильности во время инфузии: стабилизатор гасит его
  за **2,000 EU** (молния-разряд в матрицу — красиво и понятно).
- 4 стабилизатора с полными буферами = практически безопасная инфузия;
  дорогие инфузии (нестабильность 20+, ихорный путь) жгут сотни тысяч EU —
  честная цена автоматизации.
- Не заменяет свечи/черепа полностью: стабилизатор Гасит события, а базовую
  нестабильность снижают только традиционные предметы. Магия + техника, а не
  техника вместо магии.

## 6. Эссентиальная Горелка (Essentia Burner) — тир 2 (опционально, из EMT)

Генератор, сжигающий эссенцию в EU — «морковка» для техника заглянуть в магию.

| Аспект | EU за 1 ед. |
|---|---|
| Ignis, Potentia | 400 |
| Arbor, Herba | 100 |
| Perditio | 250 |

- Скорость: 16 EU/t. Подключается к трубам эссенции.
- Курсы согласованы со «вторым законом» (v3 §2): все < 500 EU/ед., петля
  через Антиадаптатор (500 EU → 1 ед.) убыточна или нейтральна. В таблицу
  канона v3 добавить строку при реализации.
