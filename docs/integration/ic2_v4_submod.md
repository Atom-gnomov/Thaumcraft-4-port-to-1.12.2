# v4 | Сабмод: архитектура, зависимости, обнаружение аддонов IC2
## Решение: интеграция — ОТДЕЛЬНЫЙ мод-аддон, не часть TC4 Unbound

---

## 1. Ключевое решение

Весь контент интеграции (v1–v4) живёт в **отдельном сабмоде**, а не в TC4 Unbound.

Причины:
- TC4U остаётся чистым портом ТК4 — не тянет IC2 API в свой jar.
- Сабмод может обновляться/балансироваться независимо, свой номер версии.
- Игроки без IC2 не получают мёртвый контент и лишние вкладки.

**Правка ко всем v3-докам:** всё, что там описано, реализуется в сабмоде.
Ссылка из README обновлена.

### Рабочие названия (выбрать одно)
| Вариант | Комментарий |
|---|---|
| **Thaumic Industry** | по образцу Thaumic Tinkerer/Energistics — узнаваемый паттерн «Thaumic X» |
| Unbound Industry | подчёркивает связь с TC4 Unbound |
| Electro-Magic Unbound | оммаж EMT, сразу понятно ветеранам 1.7.10 |

Предлагаемый modid: `thaumicindustry` (или `tc4u_industry`).

## 2. Зависимости

| Мод | Тип | Поведение |
|---|---|---|
| TC4 Unbound | **required** | база |
| IC2 (Experimental 1.12.2) | **required** | база |
| METS (More Electric Tools) | optional | модуль `mets` — см. §4 |
| Advanced Solar Panels | optional | модуль `asp` — см. §4 |
| SRP (Scape and Run Parasites) | optional | модуль `srp` — весь контент part3/part4, гейты фаз |
| Thaumic Tinkerer (порт) | optional | модуль `kami` — Ихоро-Квантовая броня |

Без опционального мода его модуль просто не регистрируется: ни предметов,
ни исследований, ни падающих рецептов. В Таумономиконе вкладка «Синтез»
показывает лорную заглушку «требуется X», если модуль выключен.

## 3. Структура модулей (код)

```
thaumicindustry/
├── core/          — аспекты IC2, рецепты машин, конвертеры, оверклокер,
│                    компоненты жезлов, электрочернильница (v3-канон)
├── armor/         — гибридная броня, два пути (ic2_v4_armor.md)
├── entities/      — техно-духи, житель, голем, босс (ic2_v4_entities.md)
├── prodchains/    — новые механизмы пайплайнов (ic2_v4_prodchains.md)
├── compat/mets/   — контент при наличии METS
├── compat/asp/    — контент при наличии Advanced Solar Panels
├── compat/srp/    — ветка паразитов
└── compat/kami/   — ихорный путь брони
```

Каждый модуль: `boolean isEnabled()` = `Loader.isModLoaded(...)` **И**
флаг в конфиге (`config/thaumicindustry.cfg`) — любой модуль можно
принудительно выключить для сборок.

**Пометка реализации:** точные modid аддонов сверить на старте
(`mets`, `advanced_solar_panels` — проверить по факту jar-ов, у
Advanced Solars Classic другой modid). Захардкоженные строки — в один
класс `CompatIds`.

## 4. Принцип работы с аддонами IC2

**Правило рецептурной адаптации:** при наличии аддона рецепты *повышаются*
до его материалов, но никогда не требуют аддон жёстко.

### Модуль `asp` (Advanced Solar Panels)
- **Солнечные Гогглы Откровения**: солнечный шлем ASP + гогглы — заряжает
  себя и жезл в руке днём (курс канона: 1,000 EU = 1 вис).
- **Sunnarium в тигле** → источник Lux/Potentia эссенции (плавится как предмет).
- Иридиевые компоненты жезлов (v3) получают альт-рецепт через Sunnarium
  (дешевле по иридию, дороже по солнечным компонентам).
- Идея-кандидат: «Лунная панель» — Ultimate-панель + Alienis: генерирует
  ночью больше, чем днём (зеркало обычной солнечной). Черновик, баланс TBD.

### Модуль `mets` (More Electric Tools)
- METS закрывает электроинструменты — **мы их не делаем вообще** (см. §5).
- Лазерные компоненты METS используются в рецепте Тесла-фокуса
  (альт-рецепт вместо схем IC2).
- Высокотирные машины METS принимаются оверклокером как обычные машины IC2
  (проверить их TileEntity-иерархию — пометка реализации).
- Точный список предметов METS зафиксировать на этапе реализации и
  дополнить таблицу аспектов (`ic2_v3_machines.md` §1) их предметами.

## 5. Границы контента (что сабмод сознательно НЕ делает)

1. **Электроинструменты** (буры, кирки, лопаты, бензопилы) — не делаем:
   у IC2+METS их достаточно. Наш максимум — Электрическая Чернильница
   (v3) и предметы, которых в техномоде быть не может (жезлы, фокусы, баблсы).
2. **Дублирование ASP** — никаких своих солнечных панелей; только гибриды
   «панель+магия» при наличии ASP.
3. **Оружие как класс** — не делаем мечи/лазеры; боевая ниша — фокусы жезлов
   и Живое Оружие (SRP-модуль).
