# RT-1: Вкладка «Индустриальная Магия» (IC2)
## Только названия и связи. [ЛОРНОЕ] = не даёт рецепт, объясняет механику.

---

```
THAUM_IC2_INTRO                              ← корень; открывается при первом контакте с EU
│
├── [ЛОРНОЕ] LORE_EU_AND_VIS
│       «EU и Вис: два языка одной энергии»
│       Объясняет почему они несовместимы напрямую и нужен посредник
│
├── [ЛОРНОЕ] LORE_ELAN_VITAL
│       «Эфирная жизненная сила»
│       Объясняет почему магия дестабилизирует электросхемы без изоляции
│
├── [ЛОРНОЕ] LORE_RESONANCE_LIMITS
│       «Пределы резонанса»
│       Объясняет почему нельзя ставить Таум-Генераторы рядом друг с другом
│
│── THAUM_ORE_MACERATION
│       Дробление руд ТК (Киноварь, Янтарь, Кристаллы) в Дробителе IC2
│
│── ALUMENTUM_CANNON_AMMO
│       Алюментум как взрывной снаряд (не топливо) для IC2-пушки
│   └── IC2_THAUM_CANNON
│           Новый блок: пушка/апгрейд Rail Gun, стреляет алюментумом
│
├── NITOR_HEAT
│       Нитор как вечный пассивный источник тепла
│   └── NITOR_THERMAL_GENERATOR
│           Нитор-термальный генератор: тепло → EU
│       └── INFERNAL_FURNACE_5x5
│               Индустриальная Адская Печь (мультиблок 5×5×5)
│               Требует: THEORY_ETHER_ISOLATION (из ветки ускорителей)
│
├── THAUM_STEEL
│       Слиток Таум-Стали (Закалённое железо IC2 + Таум-металл)
│   ├── ELECTRIC_SCRIBING
│   │       Электрическая чернильница (заряжается от EU)
│   └── THAUM_CARBON_MESH
│           Таум-Углеродная Ткань (углеволокно + Praecantatio + Pannus)
│       └── VIS_CRYSTAL
│               Вис-Кристалл (Энергокристалл IC2 + Осколки + Potentia)
│
├── VIS_TO_EU_GENERATOR
│       Таум-Генератор: вытягивает ауру Ignis/Potentia из Узла → EU
│
├── EU_TO_VIS_ENGINE
│       Эфирный Двигатель: EU → наполнение Ауры / восстановление Узлов
│   └── THAUMIC_OVERCLOCKER
│           Таум-Ускоритель механизмов IC2 (потребляет Machina + Motus)
│       │
│       ├── [ЛОРНОЕ] LORE_OVERLOAD_THEORY
│       │       «Теория перегрузки сети»
│       │       Объясняет механику взрыва Флюкса при превышении лимита ускорителей
│       │
│       └── THEORY_ETHER_ISOLATION
│               Теория: Эфирная Изоляция (решение перегрузки, лимит ×2)
│           ├── THEORY_AC_VIS_RESONANCE
│           │       Теория: Резонанс Переменного Тока Вис (КПД ускорителей +25%)
│           │   └── THEORY_QUANTUM_TUNNEL
│           │           Теория: Квантовое Туннелирование Эссенции (ускорители через 1 блок)
│           └── → разблокирует INFERNAL_FURNACE_5x5 (вторая предпосылка)
│
├── WAND_ROD_STEEL
│       Стальные наконечники жезла (дёшево, +5% скидка Вис)
├── WAND_ROD_CARBON
│       Углеволоконный стержень (малая ёмкость, +15% скидка Вис)
├── WAND_ROD_QUANTUM
│       Квантовые наконечники (заряжаются в МФЭ, +25% скидка)
│       Требует: VIS_CRYSTAL
│
├── FOCUS_TESLA
│       Набалдашник: Плазма (цепная молния, тратит EU из Энергоранца)
├── FOCUS_PURIFICATION
│       Набалдашник: Очищение (выжигает биомассу SRP)
│       Требует: SRP_BIOMASS (из вкладки SRP)
│
├── GOLEM_DRILL_KIT
│       Аксессуары голема: Бур IC2 + Бат-пак (добыча в радиусе 5 блоков)
└── GOLEM_NANO_SHIELD
        Аксессуар голема: Нано-Щит (силовое поле 30 000 EU для охранных)
```
