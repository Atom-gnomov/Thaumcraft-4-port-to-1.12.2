# RT-2: Вкладка «Внеземная Биология» — Лор и Бестиарий (SRP)
## [ЛОРНОЕ] = только объясняет, ничего не открывает напрямую.

---

## Корень и Лорные исследования

```
SRP_INTRO                                    ← корень; открывается при первой встрече с паразитом
│
├── [ЛОРНОЕ] LORE_PARASITE_ORIGIN
│       «Внезвёздные гости»
│       Лор: происхождение через портал/космос, почему магия им абсолютно чужда
│
├── [ЛОРНОЕ] LORE_TAINT_RESISTANCE
│       «Сопротивление Искажения»
│       Объясняет механику конфликта: почему SRP-биомы и Taint не поглощают друг друга
│       и почему мобы Искажения атакуют паразитов
│
├── [ЛОРНОЕ] LORE_PHASE_MECHANICS
│       «Фазы вторжения»
│       Объясняет систему очков/фаз паразитов: как они накапливаются,
│       что происходит при переходе между фазами, роль Маяков и Боссов
│
└── [ЛОРНОЕ] LORE_WHY_MAGIC_FAILS
        «Почему Таумометр молчит»
        Объясняет почему обычные магические инструменты не работают на паразитах —
        нужен только полевой опыт (счётчик убийств)
```

## Бестиарий (по типам паразитов)

Каждая запись Бестиария открывается **автоматически** после N убийств данного типа.
Похожие мобы объединены в один тип.

```
SRP_INTRO
│
├── SRP_BESTIARY_TYPE_INFECTED_ANIMALS       ← Тип: Заражённые животные
│       Объединяет: заражённая корова, свинья, волк, овца, курица
│       Открывается: 15 убийств любых заражённых животных суммарно
│       Содержит: поведение, особенности передачи заражения через укус
│
├── SRP_BESTIARY_TYPE_INFECTED_VILLAGERS     ← Тип: Заражённые жители
│       Объединяет: заражённый житель деревни (все стадии)
│       Открывается: 15 убийств заражённых жителей
│       Содержит: лор о том как распространяется по поселениям
│
├── SRP_BESTIARY_TYPE_BASIC_PARASITES        ← Тип: Базовые паразиты
│       Объединяет: Buglin, Leaper, Rupter, Scout
│       Открывается: 20 убийств любых базовых паразитов суммарно
│       Содержит: анатомия, слабости, тактика боя
│   └── SRP_BESTIARY_BASIC                  ← «Сводная запись: Базовые»
│           Открывается когда изучены ВСЕ базовые типы
│           Это разблокирующий узел для PHASE_GATE_1
│
├── SRP_BESTIARY_TYPE_ADAPTED_PARASITES      ← Тип: Адаптированные формы
│       Объединяет: формы с иммунитетами (к огню, яду, магии), бронированные
│       Открывается: 20 убийств адаптированных форм
│       Содержит: как работает адаптация, что её сбрасывает
│   └── SRP_BESTIARY_ADVANCED               ← «Сводная запись: Адаптированные»
│           Открывается когда изучены все адаптированные типы
│           Это разблокирующий узел для PHASE_GATE_2
│
└── SRP_BESTIARY_TYPE_ELITE                  ← Тип: Элита и Боссы
        Объединяет: Боссы-скопления, Маяки, формы с регенерацией
        Открывается: 5 убийств элитных форм / 1 убийство Босса
        Содержит: структура иерархии роя, роль Маяков
    └── SRP_BESTIARY_ELITE                  ← «Сводная запись: Элита»
            Это разблокирующий узел для PHASE_GATE_ELITE
```
